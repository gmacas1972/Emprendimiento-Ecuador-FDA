# Análisis de Datos Funcionales del Emprendimiento en Ecuador

Este repositorio contiene los datos, código y resultados del análisis funcional de los emprendedores (cuenta propia) en Ecuador para el período 2021-2025, desagregado por provincia y área (urbano/rural).

## Estructura del proyecto
- `data/`: Datos crudos y procesados.
- `R/`: Scripts de R para el análisis.
- `outputs/`: Figuras y tablas generadas.
- `manuscripts/`: Borradores de los artículos científicos.

## Cómo reproducir el análisis
1. Abrir el proyecto en RStudio.
2. Ejecutar el script `R/fda_master.R`.
3. Los resultados se guardarán en `outputs/`.

## Artículos derivados
- Artículo 1: Brecha Territorial e Informalidad.
- Artículo 2: Género y Jornada Laboral.
- Artículo 3: Capital Humano y el Espejismo Amazónico.
